# 数据、存储与网络

DBNook 不需要产品账号。当前代码没有接入产品遥测上报服务；正常使用会访问你配置的数据库与 SSH 端点。外部凭据命令和原生备份工具由宿主执行，可能自行访问网络。VS Code 和扩展市场自身的网络行为由其设置控制。

| 内容 | 保存/使用位置 |
| --- | --- |
| 连接名称、主机、路径、分组 | VS Code 用户/工作区设置；工作区设置可能随项目提交 |
| 密码、SSH 密钥口令 | 会话内存或 VS Code SecretStorage；不写入连接导出 |
| 私钥、证书、pgpass、SSH Config | 引用扩展宿主上的文件；不把内容加入导出 |
| SQL 参数 | 当前文档会话内存，重置或关闭后清除 |
| 查询历史 | 默认关闭；启用后在宿主本地保存 SQL 与摘要 |
| 草稿与编辑备份 | VS Code 备份或扩展全局存储；恢复不会自动执行 SQL |
| 日志和诊断 | 宿主本地，用户显式生成诊断报告，不自动上传 |
| 导出和备份 | 用户选择的目标，可能包含数据和结构 |

远程环境中的路径和“本地”指扩展宿主；远程平台仍需验收。用户设置可能受 VS Code Settings Sync 影响，请自行检查。

错误文本与路径无法保证完全脱敏。分享前检查报告，避免包含业务 SQL、主机名、账号、业务数据或密钥。

开发时 npm ci 会下载依赖；首次准备离线包会从 nodejs.org 下载固定运行时。最终 Windows x64 离线 VSIX 打开 SQLite 不需要联网下载驱动。
