# DBNook 开发路线

只完善 SQLite、PostgreSQL、MySQL、MariaDB，不新增数据库种类。公开版本先作为 Preview，不把已实现的入口等同于完整交互验收。

## 一：关闭四库日用验收

此前固定清单共 36 项，正式归档为 30 项通过、以下 6 项未关闭。0.27.0 的 SQLite 剪贴板验证不代表整项四库验收通过。

| 待关闭项 | 完成标准 |
| --- | --- |
| 日期/时区 | 四库日期、时区、微秒和 MySQL/MariaDB 零日期的显示与写回 |
| SQL 编辑交互 | 真实 VS Code 中验证四库补全、格式化和当前语句范围 |
| 复制粘贴 | 四库验证 NULL、空文本、精确数值、二进制、多行预览、取消、独立读回 |
| 编辑中保存 | 四库真实键盘输入，验证 Ctrl+S、Enter、Tab、Esc 与数据库读回 |
| 连续编辑 | 两版 VS Code × 四库，至少 10 轮撤销/重做/保存/切换标签 |
| 窗口重载 | 两版 VS Code × 四库，真实 Reload Window 验证凭据、已保存值和未保存草稿 |

## 二：完善现有能力

依次完善 SQL 编辑、表结构管理、数据流转。优先修复保存、撤销、冲突检测、精度、错误提示和离线兼容。

扩展支持的 DDL、索引和约束，保持“生成预览 SQL → 核对目标 → 执行”。完善全表/查询结果导出、字段映射、预览和失败报告，再补备份恢复与比较。

## 三：高级能力

根据前两阶段结果推进复杂结构、跨库转换、完整比较/备份、执行分析和更广的平台/服务端版本矩阵。图表、图关系、Notebook 等是后续候选，不预告交付日期。
